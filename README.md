# 社媒视频保存 · 0.1.2 测试版

桌面版 Chrome 本地扩展，无需 API Key 或服务器。

## 安装和更新
1. 解压安装包，在 chrome://extensions 开启开发者模式。
2. 加载包含 manifest.json 的 social-video-saver 文件夹。
3. 已加载同一文件夹时点击扩展的「重新加载」。
4. 刷新已经打开的社媒网页，再点击插件「重新检测」。

## 使用
仅检测当前网页已加载的视频；详情页按当前帖子筛选，Instagram 轮播按地址中的 img_index 选择当前项。不会自动翻页或播放。选择网页实际提供的分辨率，预览确认后点击「下载此分辨率」。仅有一个版本时只显示一个选项，不放大画质。下载交给 Chrome 管理，可通过「下载记录」确认结果；保存位置由浏览器下载设置决定。

切换页面地址清除旧记录；不同标签页隔离。同一视频的可识别版本合并到分辨率选择器。网络签名地址保留原样，可能过期；过期后刷新原网页重试。

## 范围和限制
支持清单内 Meta、Instagram、Pinterest、TikTok 网站及 CDN 的 MP4/WebM 候选。没有「任何网站都能下载」保证。HLS/DASH 与已识别分片不直接下载，本版不合并流或分离音视频轨。blob 地址本身不可下载，页面元数据可能提供完整文件。页面未暴露完整文件、SPA 数据尚未加载或新 CDN 未在权限范围内时仍可能识别不到。先手动播放或刷新目标详情页，再重新检测。

## 权限与隐私
webRequest 观察已授权域名的视频响应；downloads 调用下载；storage.session 暂存当前页结果；activeTab 识别操作标签页。没有外部服务器、遥测或远程代码，不读取密码或导出 Cookie。仅保存你有权下载的视频，不绕过访问限制或 DRM。卸载在 Chrome 扩展管理页点击移除。

此版本为测试版；四站完整实测未全部完成，已知验证范围如上。
